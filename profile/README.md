# Project Overview

Sublime Text is a lightweight and responsive text and source code editor designed for programming, markup, configuration files, and general text editing.

It combines a minimal interface with powerful navigation, multi-selection editing, syntax highlighting, project management, automation, and package-based extensibility.

---

# Features

- Fast source code editing
- Syntax highlighting
- Multiple selections
- Multi-cursor editing
- Split editing
- Command Palette
- Goto Anything
- Project management
- File and symbol navigation
- Search and replace
- Regular expression search
- Code completion
- Build systems
- Custom key bindings
- Themes and color schemes
- Package ecosystem

Available functionality can vary depending on the installed version, packages, configuration, and operating system.

Common workflows include:

- Writing and editing code

# Goto Anything & Command Palette

Goto Anything provides quick navigation between files, symbols, and locations within a project.

The Command Palette gives keyboard-driven access to editor functionality, commands, packages, preferences, and development tools without requiring extensive menu navigation.

# Performance

Sublime Text is designed around responsive editing and fast navigation, making it suitable for both small files and larger development projects.

Performance can depend on project size, file complexity, installed packages, syntax processing, indexing, and background tools.

---

# Troubleshooting

If the editor becomes slow or unstable, temporarily disable recently installed packages and test the same project again.

For syntax, build, or completion issues, review project settings, package configuration, file associations, and build-system definitions.

Keep backups of important custom settings, snippets, and key bindings before major configuration changes.
